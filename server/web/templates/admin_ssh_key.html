Deploy keys

An agent clones public repositories anonymously; a private one needs a key. The public half and the SHA256 fingerprint are derived on save, so a key that does not parse is refused here rather than failing a job an hour later. Private material is never shown on this page — only an enrolled agent receives it.

The key must not be passphrase protected: an agent has nobody to ask.
